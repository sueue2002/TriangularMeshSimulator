- スムージング強度 lambda をスライダーで変更
- 境界頂点を固定するチェックボックス
- 反復回数、頂点数、三角形数、処理時間を表示
- GitHub Pagesで公開しやすい構成にする
- READMEにローカル起動方法とGitHub Pages公開手順を書く
